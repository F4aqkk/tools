# Чистильщик

Программа живёт в трее, следит за свободным местом на дисках и ищет мусор, когда места мало.
Ничего не удаляется без подтверждения.

## Запуск

Двойной клик по `start.bat`. При первом запуске он сам найдёт или поставит Python,
создаст окружение `.venv`, поставит библиотеки и запустит программу.

## Что где лежит

- `start.bat` — запуск и автоматическая установка
- `requirements.txt` — список библиотек
- `main.py` — точка входа
- `chistilshchik/config.py` — пути и настройки по умолчанию
- `chistilshchik/db.py` — база SQLite
- `chistilshchik/app.py` — окно и значок в трее
- `data/` — база и лог (создаётся сама, в git не попадает)
- `TZ.md` — техническое задание
