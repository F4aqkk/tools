# ТЗ: «Чистильщик» — программа для поиска мусора, когда диск заполняется

Рабочее название. Можно поменять.

## 1. Зачем это нужно

Программа живёт в фоне, следит за свободным местом на всех дисках и, когда места мало, ищет мусорные файлы. Проверка идёт только пока ПК не нагружен. Как только я начинаю грузить ПК (игра, рендер, сборка), проверка встаёт на паузу, а когда становится тихо, продолжается с того же места.

Главное правило: **ничего не удаляется без моего подтверждения.**

## 2. Мой ПК (для настроек по умолчанию)

- Видеокарта: NVIDIA RTX 4070 Super
- Процессор: Ryzen 7 5700X (8 ядер, 16 потоков)
- SSD 1 ТБ: C: (около 195 ГБ) и D: (около 800 ГБ)
- Запасной HDD 500 ГБ: сейчас не подключён, программа должна подхватить его сама, когда я его подключу
- ОС: Windows 10 (планирую Windows 11, программа должна работать на обеих)

## 3. Как программа работает

### 3.1. Когда запускается проверка
Проверка стартует, только если выполнены **оба** условия:
1. На любом диске свободного места меньше 15% (порог меняется в настройках).
2. ПК не нагружен (см. 3.2).

### 3.2. Когда проверка ставится на паузу
Пауза включается, если выполняется **любое** условие:
- загрузка видеокарты больше 50%;
- загрузка процессора от 30% в среднем по всем ядрам;
- несколько ядер почти на 100% (по умолчанию хватает 1 ядра; число меняется в настройках).

Чтобы программа не дёргалась:
- пауза включается, если нагрузка держится около 10 секунд;
- проверка продолжается, если ПК спокоен около 30 секунд;
- проверка продолжается с места остановки, а не с нуля.

Мышь и клавиатуру программа **не** учитывает. Только нагрузка.

### 3.3. Автоматическое обнаружение новых дисков
- Каждые несколько секунд программа сравнивает список дисков с запомненным.
- Когда я подключаю новый диск (например, HDD на 500 ГБ), программа сама:
  1. добавляет его в список слежения;
  2. читает размер, свободное место, тип (SSD/HDD), букву и название;
  3. показывает уведомление из трея: «Подключён новый диск D:…»;
  4. проверяет его заполненность и при необходимости запускает проверку по тем же правилам.
- Перезапускать программу не нужно.
- Диски запоминаются в базе, чтобы отличать новый диск от уже знакомого.
- По умолчанию не следим за: CD/DVD, сетевыми дисками, флешками (это можно включить в настройках).

## 4. Что считается мусором

Программа **только находит и показывает**, что можно убрать:
- временные файлы (`%TEMP%`, `C:\Windows\Temp`);
- кэш браузеров (Chrome, Edge, Firefox): показывать жёлтым, **без галочки** — он всё равно вырастет снова;
- старые логи (старше 30 дней);
- остатки обновлений Windows (только показывать размер, чистить через системный инструмент);
- кэш миниатюр: показывать, только если больше 500 МБ, **без галочки** — Windows создаст его заново;
- размер корзины;
- дубликаты файлов (сначала по размеру, потом по хешу), только в пользовательских папках;
- очень большие файлы (больше 1 ГБ) в «Загрузках» и других пользовательских папках: только показывать, решает человек.

### 4.1. Метки уверенности
- 🟢 «Можно удалять» — галочка стоит по умолчанию (временные файлы).
- 🟡 «Скорее мусор, проверь» — без галочки (старые логи, кэш браузеров, старые установщики, дубликаты).
- ⚪ «Только для сведения» — удалить нельзя, только посмотреть (обновления Windows, корзина, большие файлы, дубликаты в «Документах» и т. п.).
У каждой находки — причина простыми словами, например «Временный файл, не менялся 14 дней — 230 МБ».

### 4.2. Перенос музыки из «Загрузок» на D:
- Музыка = файлы `.mp3 .flac .wav .m4a .aac .ogg .opus .wma .ape .alac` в «Загрузках».
- Программа предлагает перенести их в `D:\Музыка`. Если папка с таким именем уже есть (в любом регистре), использует её, если нет — создаёт.
- Переносит только после моего нажатия «Перенести», как и удаление.
- Если в `D:\Музыка` уже есть файл с тем же именем:
  - точно такой же (одинаковый хеш) — копию в «Загрузках» предлагает удалить в корзину;
  - другой — переносит с новым именем: `песня (2).mp3`.
- Если на D: мало места (меньше порога из 3.1) — **предупреждает**: показывает, сколько останется на D: после переноса, и решаю я. Если места физически не хватит — не переносит.

### 4.3. Что занимает место на заполненном диске
- Для диска, где места меньше порога, — отчёт «что занимает больше всего места»: самые большие папки и файлы.
- Исключения из раздела 5 не показываются (в том числе `D:\repositori`).
- Только показывает, ничего не удаляет и не предлагает удалить.

## 5. Безопасность (самое важное)

- Удаление только после моего нажатия «Очистить».
- Сначала в корзину, а не навсегда.
- Список исключений, которые программа не трогает никогда:
  - `D:\repositori` и вообще все папки `.git`;
  - `C:\Windows`, `C:\Program Files`, `C:\Program Files (x86)` (кроме явных временных папок из пункта 4);
  - папки «Документы», «Рабочий стол», «Изображения», «Музыка», «Видео» (там только отчёт о дубликатах, без удаления);
  - любые папки, которые я добавлю в исключения сам.
- Пользователь может нажать «Не показывать этот файл больше».
- Ведётся журнал: что нашла, что удалила, когда.

## 6. Интерфейс

- Значок в трее (у часов): цвет показывает состояние (следит / идёт проверка / пауза).
- По клику открывается окно:
  - список дисков и свободное место на каждом;
  - текущее состояние (проверка идёт / на паузе из-за нагрузки / ждёт);
  - отчёт: «нашла 12 ГБ мусора» с разбивкой по категориям;
  - галочки, что очищать, и кнопка «Очистить» (с подтверждением);
  - вкладка «Настройки»: порог свободного места, порог видеокарты и процессора, число ядер, задержки паузы и продолжения, список исключений.
- Уведомления из трея: новый диск, диск заполняется, проверка закончена.

## 7. Технологии

- Python 3 + PyQt6 (окно и значок в трее, как в ExamTicketGenerator)
- `psutil` (диски, процессор, ядра)
- `nvidia-ml-py` / `pynvml` (нагрузка NVIDIA). Если NVIDIA недоступна, условие про видеокарту отключается с предупреждением в журнале.
- SQLite (запомненные диски, место остановки проверки, исключения, журнал)
- `send2trash` (удаление в корзину)
- Проверка в отдельном потоке, чтобы окно не зависало.

## 8. Как сохраняется место остановки

Таблица в SQLite запоминает: диск, этап проверки, последнюю обработанную папку. После паузы или перезапуска программы проверка продолжается оттуда.

## 9. Запуск и установка

- Проект лежит в `D:\repositori\Chistilshchik` (название папки можно поменять).
- Запуск по двойному клику на `start.bat`. Всё остальное делается само:
  1. ищет Python; если его нет, ставит автоматически;
  2. создаёт виртуальное окружение;
  3. ставит библиотеки из `requirements.txt`;
  4. запускает программу.
- Никаких ручных установок.
- Опционально: пункт «запускать вместе с Windows» в настройках.
